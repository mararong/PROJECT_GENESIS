# PROJECT GENESIS

인공 생태계를 관찰하는 웹 UI 프로토타입. 기준 문서는 `PROJECT_GENESIS_design_v1.md`의 12장과 18장이며, 실제 신경망·진화·문명 엔진은 포함하지 않습니다. 화면의 **프로토타입 시뮬레이션** 표기를 유지합니다.

## 웹에서 실행 / GitHub Pages

배포 주소: **https://mararong.github.io/PROJECT_GENESIS/**

저장소: https://github.com/mararong/PROJECT_GENESIS

`.github/workflows/pages.yml`이 `main` 푸시마다 Node.js 24에서 `npm ci` → 모델·UI 테스트 → Pages용 빌드 → 배포를 실행합니다. PR에서는 테스트·빌드만 수행합니다. 테스트가 실패하면 배포하지 않습니다. 배포 후 실제 Chrome에서 공개 주소의 세계 생성·캔버스·재생 제어·반응형·터치 등 25개 항목을 확인하고 결과/스크린샷을 Actions 아티팩트로 보관합니다.

최초 한 번 저장소 **Settings → Pages → Build and deployment → Source → GitHub Actions**를 선택해야 합니다. 이후에는 `main`에 푸시하면 자동으로 배포됩니다. 최초 설정 전 실패한 배포는 Actions의 `Test and deploy GitHub Pages`에서 `Re-run failed jobs`로 다시 실행할 수 있습니다.

Pages 빌드는 `npm run build:pages`이며 `/PROJECT_GENESIS/` 경로로 자산을 생성합니다. 로컬 개발 및 일반 `npm run build`는 기존 루트 경로를 유지합니다. 저장소 이름을 바꾸면 `package.json`의 `build:pages` 경로도 수정하세요. 배포 진행/결과는 저장소의 Actions 탭에서 확인할 수 있습니다.

## 실행

Node.js 24 이상, npm, WebGL을 지원하는 최신 브라우저가 필요합니다.

```powershell
cd D:\PROJECT_GENESIS
npm.cmd ci
npm.cmd run dev
```

브라우저에서 http://127.0.0.1:5173/ 를 엽니다. Windows PowerShell에서 `npm.ps1` 실행 정책 오류가 나면 위와 같이 `npm.cmd`를 사용하세요. 다른 운영체제에서는 `npm`을 사용하면 됩니다. 의존성이 이미 설치되어 있다면 `ci`를 생략할 수 있습니다.

```powershell
npm.cmd test
npm.cmd run typecheck
npm.cmd run build
npm.cmd run preview
```

빌드 산출물은 `dist/`이며 `preview`의 기본 주소는 http://127.0.0.1:4173/ 입니다. `index.html`을 파일로 직접 열지 말고 개발 서버 또는 미리보기 서버를 이용하세요. `package-lock.json`으로 의존성을 고정했습니다.

## 구현한 기능

- 시작 화면, 실제로 저장된 최근 생성 설정, 현재 관측 이어가기.
- 3단계 세계 생성: 이름·씨드·균형/숲/건조 프리셋·10~100개체 검증, 지형/신체 미리보기, 입력값 유지.
- 동일 씨드와 설정에서 동일한 128×128 지형·초기 배치·신체·먹이 생성. 기본 50개체, 세 가지 종 표식.
- PixiJS 8 캔버스, 기관 그래프에 따른 외형, 화면 밖 렌더링 생략, 틱 사이 위치 보간.
- 클릭·터치 선택, 호버 설명, 선택 외곽선, 더블클릭/버튼 추적, 추적 중단, 배경 드래그/터치 팬, 휠/핀치 줌, 배율 제한, +/- 버튼, 미니맵 이동.
- 같은 개체의 개요·신체·유전자 탭. 위치·에너지·건강·나이·실제 행동·최근 사건, 부품별 강조, 사망 개체의 마지막 기록 유지.
- 규칙 기반 이동·먹이 탐색·섭취·자원 소비·에너지 고갈·사망·멸종. 기본 논리 속도 10틱/초, 1×/2×/5×/10×, 일시정지, 정확히 한 틱 진행, 실제 처리량 표시.
- 초기 배치·섭취·선택·사망·멸종 사건의 고유 ID·발생 틱·관련 개체 기록. 필터, 이전 사건 더 보기, 사건 대상/위치 강조.
- 자연 관찰 / 먹이 분포 / 종별 분포 레이어와 범례. 한 번에 하나의 레이어를 사용합니다.
- 데스크톱 3분할, 태블릿 정보 드로어, 모바일 25%·60%·전체 높이 시트 및 스와이프. 시트 아래 재생바 유지.
- 빈 상태, 멸종·사망 상태, 렌더러 실패와 재시도, 생성 설정 저장 실패 안내. 키보드 포커스, 모달 포커스 유지/복원, `prefers-reduced-motion` 대응.

## 조작

| 조작 | 기능 |
|---|---|
| 생명체 클릭·터치 | 선택과 상세 패널 열기 |
| 세계 개요의 개체 목록 | 키보드로 개체 선택 |
| 더블클릭 / `F` | 선택 개체 추적 / 추적 중단 |
| 배경 드래그 / 터치 팬 | 선택을 유지한 채 카메라 이동 |
| 휠 / 핀치 / `+` `-` | 확대·축소 |
| 미니맵 클릭 / 포커스 후 방향키 | 카메라 이동 |
| `Space` | 재생·일시정지 |
| 일시정지 중 `→` | 한 틱 진행 |
| `Esc` | 모달 → 정보 패널 → 선택 순으로 닫기 |
| 모바일 시트 핸들 클릭 / 상하 스와이프 | 작은 / 큰 / 전체 시트 전환 |

입력 중에는 세계 단축키를 실행하지 않습니다. 백그라운드 탭으로 전환하면 자동 일시정지하며, 복귀 시 사용자가 재생합니다. 사건 클릭은 발생 시각을 표시하고 관련 대상을 강조합니다. 과거 상태를 재생하는 기능은 아닙니다.

## 구조와 실제 엔진 연결

```text
src/app/                 화면 전환과 UI 상태
src/components/          레이아웃, 인스펙터, 타임라인, 모달
src/features/world/      Pixi 라이프사이클, 카메라 입력, 지형 미니맵, 생성 마법사
src/features/creature/   Pixi 외형과 공통 신체 그래프 계산
src/simulation/         결정적 생성기, MockEngine, SimulationClock, SimulationAdapter
src/state/              시뮬레이션 훅, UI 타입, 개체 조회, 생성 설정 보관
src/types/              Creature / WorldState / PrototypeEvent 데이터 계약
src/styles/             디자인 토큰, 공통 스타일, 관측소 반응형 스타일
```

`WorldScene`은 스냅샷을 그리며 모델 값을 변경하지 않습니다. `MockEngine`만 논리 틱을 진행합니다. `SimulationClock`이 경과 시간을 고정 논리 틱으로 변환하므로 배속이 화면 프레임 수나 개체 이동 공식에 직접 곱해지지 않습니다. 선택·추적·레이어·패널 상태는 월드와 분리했습니다.

실제 엔진으로 확장할 때 `SimulationAdapter`의 `getSnapshot`, `step`, `reset`, `selectCreature`, `dispose` 계약을 구현하고 `useSimulation`의 어댑터 생성 지점을 교체하세요. 이후 Web Worker 응답을 기다리는 비동기 계약으로 확장할 수 있습니다. 현재 엔진은 동기식이며 신경망 활성화나 문명 사건을 생성하지 않습니다.

## 저장과 한계

`localStorage`의 `genesis.world-configs.v1`에 최근 **생성 설정**을 최대 8개 보관합니다. 이 항목을 열면 씨드와 조건으로 처음부터 새로 생성합니다. 틱·생명체의 진행 상태는 새로고침하면 사라집니다. 존재하지 않는 세계나 저장 완료 표시를 만들지 않습니다. 대규모 이벤트는 현재 실행의 메모리에 유지하므로 장시간 실험용 저장 엔진을 대신하지 않습니다.

건강과 유전자 수치는 목업 모델의 정의된 값입니다. 종 S1~S3은 초기 시각적 분류이며 실제 종 분화 결과가 아닙니다. 기본 번식은 꺼져 있습니다. `MockEngine`에는 테스트 가능한 선택적 `demoReproduction` 복제 규칙이 있지만 생성 화면에서 활성화하지 않습니다.

## 검증

- `npm.cmd test`: 모델 테스트 13개 + Vitest/React Testing Library 테스트 14개.
- `npm.cmd run typecheck`, `npm.cmd run build`.
- 개발 서버 실행 후 `npm.cmd run test:browser`: 실제 Chrome에서 생성·캔버스 클릭·추적·팬·줌·틱/배속·타임라인 및 1440×900 / 768×1024 / 390×844 반응형, 에뮬레이션 터치를 포함한 25개 항목 검증. 결과와 스크린샷은 `docs/qa/`에 기록합니다.
- Chrome 위치가 다르면 `CHROME_PATH` 환경변수에 실행 파일 경로를 지정하세요. 이 QA 스크립트는 독립된 테스트용 프로필을 `tmp/`에 생성합니다.

DOM 테스트에서는 GPU 캔버스를 대체하며, 실제 Pixi 검증은 브라우저 QA로 분리했습니다. 단계별 증거와 남은 검증 범위는 [구현 기록](docs/IMPLEMENTATION.md)에 정리했습니다. 실제 터치 기기와 중저사양 기기의 FPS 벤치마크는 수행하지 않았습니다.

## 미구현 기능

실제 신경망·학습·NEAT, 유전적 진화·자연선택·종 분화, 기억·사회관계·문명/기술 형성, 유전자 편집 실험, 계통수 분석, 과거 상태 되감기·스냅샷 복원·평행세계 비교, 대규모 영구 저장, 서버/계정/멀티플레이 및 백엔드 서버 배포. 고급 메뉴는 준비 중으로 비활성화하고 동작하지 않는 저장·개입 버튼을 표시하지 않습니다.
