# 구현 및 검증 기록

기준: `PROJECT_GENESIS_design_v1.md` 12장, 18장. 실제 진화·신경망·문명 엔진과 서버 배포는 범위 밖이다.

## 기존 코드 보존

- 작업 시작 시 Git 저장소가 아니었으며, 기존 소스를 `tmp/baseline/`에 복사했다.
- React/Vite/TypeScript 설정, 디자인 토큰, 결정적 지형 생성기, 신체 그래프, Pixi 렌더러, 카메라 좌표 변환을 이어서 사용한다.
- 기존 코드는 화면 골격과 아직 화면에 연결되지 않은 P2 로직으로 구성되어 있었다.

## 단계별 기록

P1 → P2 → P3 → P4 → P5 순서로 소스를 연결한다. 각 단계의 검증 결과와 미검증 항목을 구분한다. 의존성 설치가 불가능한 환경에서 화면 검증을 통과했다고 기록하지 않는다.

- 초기 모델 테스트: `node --test scripts/core.test.mjs` — 4/4 통과.
- 초기 의존성 설치: npm registry 접근 `EACCES`. 샌드박스 추가 권한 요청은 승인 정책에서 거절됨. 로컬 캐시에도 React/Vite/PixiJS가 없음.
- 사용자가 외부 터미널에서 설치를 완료한 뒤 빌드와 브라우저 검증을 재개했다. 일반 브라우저 도구는 Windows 샌드박스 오류로 실패했으며, 별도 테스트 프로필의 headless Chrome으로 실제 UI 검증을 수행했다.

## 자동 검증 결과

- 모델: `node --test scripts/core.test.mjs` 13/13 통과.
- UI: `npm.cmd run test:ui` 14/14 통과. DOM 간 테스트 격리와 저장 실패·손상 데이터도 검증했다.
- 실제 브라우저: `node scripts/qa-browser.mjs` 25개 항목 통과, 브라우저 애플리케이션 오류 0개. 브라우저 터치 에뮬레이션으로 팬·핀치와 선택 보존도 검증했다. [기계 판독 결과](qa/browser-results.json).
- TypeScript와 프로덕션 빌드 통과. React 벤더 코드를 분리하여 초기 단일 청크 크기를 줄였다.

## 보존·통합·추가 수정

- 작업 중 외부에서 추가된 App/엔진/인스펙터/타임라인 소스도 `tmp/incoming/`에 보관하고 통합했다. 기존 모델 테스트 13개를 보존했다.
- 중복 관측소 CSS는 백업 후 `observatory.css`로 통합했다. `globals.css`는 기존 기본 화면·공통 컨트롤/마법사 스타일을 유지한다.
- 잘못된 새 세계 생성이 현재 엔진을 먼저 해제하지 않도록, 새 엔진 생성 성공 후 기존 엔진을 해제한다.
- 브라우저 QA 프로필 파일을 Vite 감시 대상에서 제외하여 Windows 임시 파일 잠금으로 인한 개발 서버 종료를 방지한다.
- 지형을 16×16 타일 청크로 캐시하여 카메라 이동마다 전체 지형 그래픽을 재생성하지 않는다. 화면에 필요한 청크만 렌더링한다.
- headless Chrome의 `--disable-gpu` 모드에서만 나타난 리사이즈 후 캡처 공백은 ANGLE/SwiftShader 모드로 QA 환경을 조정해 해소했다. 진단용 GPU 읽기나 불필요한 렌더러 재생성 코드는 제품에서 제거했다.

## 검증의 범위와 한계

실제 Chrome에서 마우스·캔버스·리사이즈·모바일 시트 UI와 에뮬레이션 터치를 확인했다. 실제 휴대폰의 멀티터치 핀치/스와이프와 기기별 성능은 추가 확인 대상이다. 모델 테스트의 사망·멸종은 에너지/먹이 조건을 고정해 검증하며, 사용자 세계를 강제로 멸종시키는 개발용 버튼은 추가하지 않았다. 신경망·문명·실제 진화·과거 스냅샷은 구현/검증 대상으로 주장하지 않는다.
